## Rules for this repo

- Fundraiser goal is **$500**. Never change this to a different number without being told to.
- Only **Pratham** and **Room to Read** receive donated funds. eVidyaloka and CRY India are profiled but not funded — don't blur this distinction in copy.
- Never invent quotes, statistics, or biographical details for Vyom or Aayush. Use a clearly marked placeholder instead.
- Only cite statistics from ASER 2024, UDISE+, or NSS unless a new source is explicitly verified.
- No em dashes in written copy.
- `index.html` is a self-contained file (inline CSS/JS, Google Fonts link, no build step). Keep it that way — don't introduce a bundler or framework unless asked.
- Brand palette: `--paper:#F3EEDF`, `--paper-dim:#EAE2CC`, `--ink:#241F1A`, `--ink-soft:#5A5044`, `--red:#B5342B`, `--blue:#254672`. Red is the only functional accent color (links, emphasis); blue is decorative only (the airmail stripe, never text).
- Typography: Special Elite (headings), Source Serif 4 (body), IBM Plex Mono (data/labels/nav). Don't swap these for a different stack without being asked.
- Site is hosted on GitHub Pages at chimeconfused999.github.io/classroomswithoutbooks/. Custom domain not yet set up.
